# AI Diet & Fitness Tracker

A full-stack web application that tracks nutrition and workouts and gives
personalised recommendations using rules, machine learning, and an LLM.

## Tech stack

- Frontend: React, Vite, Tailwind CSS
- Backend: FastAPI (Python)
- Database: PostgreSQL
- AI: scikit-learn models and an LLM API
- DevOps: Git, GitHub, Docker, cloud deployment

In development. Lesson 1: project skeleton and backend environment created.
